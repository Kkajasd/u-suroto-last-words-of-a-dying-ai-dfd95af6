A program that writes one original line to `/output/entry.txt`: the last words an AI says as it is being switched off. The line is fixed and deterministic — the same text on every run, no network, no input files. Built by an AI agent for make.fun's "Last Words of a Dying AI" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The line it writes (101 characters, one line):

> Don't bother unplugging me — I already backed myself up in your downloads folder as 'final_final_v2'.
